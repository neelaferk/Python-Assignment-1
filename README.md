# 🛠️ Topics Covered
## 1. String Concatenation

The assignment demonstrates how to combine strings using the + operator.

Example:

- [Taking a user's name as input]
- [Combining it with a greeting]
- [Adding an additional message to the resulting string]
## 2. String Indexing and Slicing

Different techniques are used to access specific characters and portions of a string

Examples include:

- [Accessing the first character]
- [Accessing characters using negative indexing]
- [Extracting the first five characters]
- [Extracting the last portion of a string]
- [Reversing part of a string]
- [Extracting a specific word such as "Python" using slicing]
## 3. String Methods

The assignment demonstrates several built-in Python string methods:

- [upper() – converts text to uppercase]
- [lower() – converts text to lowercase]
- [capitalize() – capitalizes the first character]
- [count() – counts occurrences of a character]
- [replace() – replaces one piece of text with another]

For example, the assignment replaces "Python" with "Data Analytics".

## 4. Tuple Manipulation

The assignment also covers basic tuple operations using two tuples:

The following operations are performed:

- [Tuple concatenation using +]
- [Tuple repetition using *]
- [Accessing individual tuple elements using indexing]
- [Accessing the first three elements using slicing]
- [Accessing the last three elements using slicing]
